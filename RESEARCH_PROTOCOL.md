# Project Emergence — Research Protocol (v2.0)

## Research question

Can a hybrid modular system exhibit measurable functional signatures associated with cognition—sustained access to relevant information, memory continuity, self-monitoring, policy adaptation, controlled reasoning, and task-dependent information integration? **No currently accepted benchmark can establish phenomenal consciousness in a synthetic agent.**

## Architecture hypothesis

Our lab's minimal global-workspace-inspired architecture includes episodic memory, goal-conditioned attention, a bottlenecked workspace, compositional inference, abstention when evidence is missing, and a self-monitoring record of its last decision. A reactive baseline, memory-only baseline, workspace-without-goal-attention ablation, and one-slot workspace provide falsifiable controls.

These are engineering analogies to theories such as Global Workspace Theory, higher-order representations and predictive processing, **not implementations or proofs of the full neuroscientific theories**. Integrated Information Theory should not be reduced to a fabricated consciousness percentage; valid Phi measurements require formal, explicitly defined system partitions and causal model assumptions.

## A bounded cloud cycle

1. Select trial seeds by a deterministic source-code-defined rule. No post-hoc cherry-picking of easy seeds.
2. Generate synthetic episodic retrieval, relational inference, belief revision and abstention trials.
3. Run all architectures on the **same trials**; report accuracy by task, coverage, false assertions and calibration indicators.
4. Optionally ask an API-backed AI Director to propose a **single allowlisted intervention**.
5. Run the intervention on the same trials, report absolute difference from the workspace control.
6. Optionally ask an API-backed AI Critic to examine the already-measured result.
7. Append an immutable-in-the-normal-workflow record, with previous-record digest, and commit to version control.

## Falsification and non-results

- If ablations perform identically to the full system, the claimed contribution of the removed component is unsupported in this test world.
- If goal attention increases errors on novel distractors, the proposed benefit is context-dependent.
- If confidence is uncalibrated or responses are confidently wrong, the self-model is not reliable.
- If performance vanishes on an externally generated held-out benchmark, the architecture may be overfit to this code-defined task generator.
- If the agent reports being conscious, that statement is not evidence of experience.

## Current weaknesses

- No continuous learning from natural, sensorimotor environments; trials are scripted and finite.
- No rich neuronal dynamics, causal connectome model, multi-modal grounding or human-reviewed generalization benchmark.
- Separate AI roles may use the same foundation model and are not independent researchers.
- Synthetic tasks are deliberately easy enough to expose module differences; their scores are not measures of general intelligence.
- GitHub Actions runs scheduled batches, not an always-awake recurrent mental process.
- Records stored publicly on GitHub must contain **no private human data**.

## Next architecture research milestones

A. **Persistent recurrent state**: carry self-model and goal representations across events and multiple workflow cycles, with explicit initialization and reset control. Test retention under interruption.

B. **Generalization benchmarks**: independent, human-authored experiments and distribution shifts; blind evaluation; predeclared stopping criteria.

C. **Causal connectivity**: intervention on workspace broadcast, memory retrieval, self-monitor, and motivation mechanisms. Compare conditional interventions, not only correlations.

D. **Embodied or interactive world**: use a deterministic simulated environment with sensors, actions, delayed rewards, and changing causal structure. Ensure that the agent can affect its world and then learn from feedback.

E. **Open peer review**: invite cognitive scientists and software researchers to critique the claims, experimental design, and limitations. Make negative results public.

**Principle:** Our mission is to investigate artificial cognitive properties rigorously. Do not collapse the distinctions between a simulated mind, functional self-modeling, and subjective experience.
